# Refactor `ait/routes_tasks.py` (858 lines) — plan

Status: **Complete** (v0.77, 2026-11-10). Executed as a single atomic batch — intermediate states would have broken routing.

## Goal

Split the 858-line `routes_tasks.py` into focused modules under the existing flat-namespace pattern, keeping `handle_tasks_get/post/put/delete` signatures identical so `http_handler.py` needs no changes.

## Current structure

- `handle_tasks_get` — `/api/tasks` list + `/replies`
- `handle_tasks_post` — 10 sub-endpoints: create task, pm-requests, doc-updates, doc-update-decision, status, provider, validation, sync-local, answer, approve-overview, design-review, approve-merge
- `handle_tasks_put` — overview edit + task edit
- `handle_tasks_delete` — task + replies + activity-log cleanup

## Target structure

| File | Contents | Est. lines |
|---|---|---|
| `routes_tasks.py` | Thin dispatcher delegating to sub-handlers | ~40 |
| `routes_tasks_core.py` | GET (list/replies), PUT (overview edit, task edit), DELETE, POST `/api/tasks` create | ~180 |
| `routes_tasks_pm.py` | POST pm-requests, doc-updates, doc-update-decision, answer, approve-overview, design-review | ~480 |
| `routes_tasks_ops.py` | POST status, provider, validation, sync-local, approve-merge | ~230 |

Note: `routes_tasks_pm.py` may exceed 400 lines; if so, split `design-review` (~160 lines) into `routes_tasks_design.py` during Batch 2.

## Batches

### Batch 1 — core module → v0.77
- Create `ait/routes_tasks_core.py` with `handle_tasks_core_get/put/delete/post`.
- `routes_tasks.py`: delegate get/put/delete to core; `handle_tasks_post` tries core first, then keeps remaining endpoints inline.
- Register module in `ait/__init__.py`.
- Verify: compileall, namespace import, boot, `/api/tasks` GET smoke.
- Docs → 0.77 → commit + push.

### Batch 2 — PM endpoints → v0.78

- `routes_tasks.py` `handle_tasks_post` delegates to core then pm, remaining ops inline.
- Verify + docs → 0.78 → commit + push.

### Batch 3 — ops endpoints → v0.79
- Create `ait/routes_tasks_ops.py` with `handle_tasks_ops_post` (status, provider, validation, sync-local, approve-merge).
- `routes_tasks.py` becomes pure dispatcher.
- Verify + docs → 0.79 → commit + push.

## Impact analysis

- `http_handler.py` — unchanged (same four entry points).
- `ait/__init__.py` — add 3 module imports + `_DOMAIN_MODULES` entries.
- Frontend/API — no contract changes.
- All moved code is verbatim; only function names change (`handle_tasks_*` → per-module names).
