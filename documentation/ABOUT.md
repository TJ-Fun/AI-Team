# Personal AI Team

Version: **0.152**

Release date: **2026-11-21**

Project: [github.com/TJ-Fun/AI-Team](https://github.com/TJ-Fun/AI-Team)

Personal AI Team is a self-hosted project workspace for planning work, coordinating AI agents, and tracking task outcomes. It combines a project board and a provider-backed PM/PO chat with GitHub-backed code workflows and configurable AI-provider connections.

- Project board with drafts, statuses, acceptance checks, and versioned per-project context documents
- PM/PO chat with on-request document access and approval-gated document edits
- Ordered provider/model routing per role with retries, streaming, and automatic failover
- GitHub pull-request workflow with QA review, merge gates, and guarded local checkout sync
- Phased release planning with progress trackers, env-setup tasks, and staged replan chains
