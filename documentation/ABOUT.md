# Personal AI Team

Version: **0.27**

Release date: **2026-11-01**

Project: [github.com/TJ-Fun/AI-Team](https://github.com/TJ-Fun/AI-Team)

Personal AI Team is a self-hosted project workspace for planning work, coordinating AI agents, and tracking task outcomes. It combines a project board and a provider-backed Orchestrator chat with GitHub-backed code workflows and configurable AI-provider connections.
